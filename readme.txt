Connects Million Dollar Script grids to ImageGrid for hosted rendering and authenticated tile delivery.

== Description ==

MDS ImageGrid connects MDS3 zoomable grids to the separately subscribed ImageGrid service. Site owners enter their ImageGrid API URL and API key, then submit grid render jobs and serve ready remote tiles through WordPress without exposing the API key to browsers.

== Installation ==

1. Install and activate Million Dollar Script 3.
2. Install and activate MDS ImageGrid.
3. Open Million Dollar Script > ImageGrid.
4. Save the ImageGrid API URL and API key.
5. Test the connection, then render a grid.
