Free connector that connects Million Dollar Script grids to ImageGrid for hosted rendering and authenticated tile delivery.

== Description ==

Million Dollar Script ImageGrid connects Million Dollar Script zoomable grids to the separately subscribed ImageGrid service. Site owners can connect through the hosted ImageGrid app or enter an ImageGrid API URL and API key manually, then submit ImageGrid grid_render jobs and serve ready remote tiles through WordPress without exposing the API key to browsers. ImageGrid settings and grid render controls are added only when this extension is active.

== Installation ==

1. Install and activate Million Dollar Script.
2. Install and activate Million Dollar Script ImageGrid.
3. Open Million Dollar Script > Dashboard > ImageGrid.
4. Connect ImageGrid or save the ImageGrid API URL and API key manually.
5. Test the connection, then render a grid from Million Dollar Script > Dashboard > ImageGrid or Grids > Edit Grid > ImageGrid.
